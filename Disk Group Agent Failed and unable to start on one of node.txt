Solution:
========



Refer below steps to fix Agent Failed issue:

 
1.     Try to Stop/Start failed VCS agent with following command

#haagent -stop <Agentname> -sys <Node name>
#haagent -start <Agentname> -sys <Node name>
 
2.     Verify types.cf file in /etc/VRTSvcs/conf/config/types.cf and /etc/VRTSvcs/conf/types.cf. If there is difference found between both the files then replace the types.cf file
 
3.     Verify VRTSvcsag package binary with below command and if binary size shows zero, Reinstall the Agent binary
 
 
PKGINST: VRTSvcsag
      NAME: Veritas Cluster Server Bundled Agents by Symantec
 CATEGORY: system
      ARCH: sparc
   VERSION: 5.1
   BASEDIR: /
    VENDOR: Symantec Corporation
      DESC: Veritas Cluster Server Bundled Agents by Symantec
    PSTAMP: 5.1.002.000-5.1RP2-2010-08-26_19.00.00
 INSTDATE: Mar 22 2011 21:10
    STATUS: completely installed
     FILES:      343 installed pathnames
                   4 shared pathnames
                  59 directories
                 211 executables
                6205 blocks used (approx)
 
4.     Verify if Process table having any defunct processes. If found then kill those processes and try to start Agent again on affected node.
