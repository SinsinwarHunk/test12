========================= OFF Line ==============================================
1- offline the zones
	hagrp -offline <zone name> -sys <host to be down i.e. B1>
	hagrp -offline ravenu1 -sys longmgctrskpltb1

	wait for few minutes to make sure that resource be "OFFLINE"

2- freeze the node / resorces
	hagrp -freeze <zones running on another node> -sys <another node i.e. P1> -persistent
	hagrp -freeze ratappp1 -sys longmgctrskpltp1 -persistent
	hagrp -freeze ravenp1 -sys longmgctrskpltp1 -persistent	
	
	check for groups frozen hastatus -sum

3- rename the VCS start script
	cd /etc/rc3.dcd /etc/rc3.d
	mv S99vcs s99vcs

4- Stop the VCS Engine
	hastop -local -force

5- confirm that VCS engine has stoped
	hastatus -sum #this should not work

6- init 0

============================= ON LINE ==============================================

1- if VCS not started (hastatus not work) start the VCS:

	hastart

2- unfreez the groups:
	hagrp -unfreeze ratappp1 -sys longmgctrskpltp1 -persistent
	hagrp -unfreeze ravenp1 -sys longmgctrskpltp1 -persistent

3- check if resources are offline, make it online.

4- match the hastatus -sum output.

5- rename the s99vcs to S99vcs in /etc/rc3.d
